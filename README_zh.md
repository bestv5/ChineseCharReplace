# Character Auto Replacemet - Plugin（字符自动替换插件）

## (PS: 虽然大家都用上AI编程了，这个插件用处不大了。但我还是更新了一下，增加了一个自适应替换的配置，根据当前输入的内容判断是否要进行替换，送给那些像我一样内网开发没有使用AI编程的朋友们)

# 功能说明:
1. 该插件自动替换输入的中文标点,不用刻意切换输入法了，
2. 2.x 全新重构，增加过根据输入内容判断是否进行替换，也有参数配置。配置在`settings - Tools -  CharAutoReplace`
4. 支持 idea 2020.3 以上版本；同样适用于 CLion、Rider 等基于 IntelliJ 平台的 IDE。

# 使用说明：
1. 下载安装插件。
2. 在  `
   settings - Tools -  CharAutoReplace
   `中配置自己想替换的符号（默认配置了大部分中文标点）。
3. 最好关闭输入法中，自动中文变英文标点功能。
